# Nonato Labs

Este projeto usa a assinatura operacional da Nonato Labs para trabalhar com agentes de IA.

## Assinatura

```text
Nonato Labs
AI-native project workflow
Codex inicia. Gemini planeja. Lovable prototipa. Claude revisa riscos.
O repositório guarda a verdade.
```

## Princípio

Conversas ajudam a decidir, mas a fonte oficial do projeto fica no repositório:

- `AGENTS.md`
- `docs/`
- `tasks/`

## Como este projeto deve operar

1. Codex inicia ou organiza o projeto.
2. Gemini entra quando o escopo estiver vago.
3. Codex executa tarefas claras.
4. Lovable prototipa UI quando necessário.
5. Claude revisa apenas riscos relevantes.
6. `docs/AI_HANDOFF.md` registra o estado para o próximo agente.
